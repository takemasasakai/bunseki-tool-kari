📖 APIキーの取得方法（初めての方）
  1. Google Cloud Console にアクセスし、Googleアカウントでログイン
  2. 新しいプロジェクトを作成（名前は何でも可・親リソースは「組織なし」でOK）
  3. 左メニュー「APIとサービス」→「ライブラリ」→「YouTube Data API v3」を有効化
  4. 「認証情報」→「認証情報を作成」→「APIキー」をクリックしてコピー
  5. 上のAPIキー欄に貼り付けて検索してください
  6. 無料枠：1日10,000ユニット（検索1回＝100ユニット）で十分使えます
